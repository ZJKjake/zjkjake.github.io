# Jake Zhang

Jiankun (Jake) Zhang personal website.

## Develop

    npm install
    npm run dev
    npm run build
    npm run check

## Key files

- src/pages/index.astro — the complete public portfolio page
- src/data/site.ts — contact details, resume path, navigation, and media flag
- src/styles/global.css — palette, dark mode, typography, and shared styling
- src/content/work/ — source notes and verified project metrics
- public/media/ — resume, recovery video, reports, and project images

## Deploy

Push main to build and publish the site through GitHub Pages.
